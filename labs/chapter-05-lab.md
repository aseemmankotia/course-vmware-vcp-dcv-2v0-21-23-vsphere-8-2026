# Chapter 5 Lab: Datastores: VMFS, NFS, Storage Adapters, and Multipathing

**Estimated time:** 30 minutes

## Exercise

Configure a software iSCSI adapter with CHAP authentication, present an iSCSI LUN, format it as a VMFS6 datastore, and set the path selection policy to Round Robin

## Key takeaway

Storage adapter and multipathing choices must match the array's active/active or active/passive behavior, and the exam expects precise PSP and RDM mode selection for described requirements.
