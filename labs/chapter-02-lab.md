# Chapter 2 Lab: vCenter Server Deployment and Inventory Design

**Estimated time:** 30 minutes

## Exercise

Deploy a vCenter Server Appliance using the VCSA installer GUI wizard, select an appropriate deployment size for a 100-VM environment, then build a datacenter/cluster inventory structure

## Key takeaway

vCenter Server sizing and topology decisions directly affect scalability and resiliency, and the exam tests whether you can match the right deployment model to a stated environment size.
