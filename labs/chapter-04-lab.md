# Chapter 4 Lab: VMkernel Adapters, NIC Teaming, and Network I/O Control

**Estimated time:** 25 minutes

## Exercise

Configure a VMkernel adapter for vMotion traffic with a dedicated TCP/IP stack, set NIC teaming to Route based on physical NIC load, and apply an NIOC share value to the vMotion traffic class

## Key takeaway

Traffic separation, teaming policy, and NIOC settings must be deliberately matched to workload requirements — the exam tests whether you pick shares vs limits and the correct teaming policy for a given scenario.
