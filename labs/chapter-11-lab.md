# Chapter 11 Lab: Security, Roles, Lifecycle Management, and Performance Troubleshooting

**Estimated time:** 30 minutes

## Exercise

Create a custom role with least-privilege permissions for a junior admin, assign it at the cluster level with propagation, then run esxtop in a nested lab and identify a VM with elevated %RDY indicating CPU contention

## Key takeaway

Security design relies on precise permission propagation and certificate management, while performance troubleshooting hinges on correctly interpreting esxtop counters like %RDY rather than surface-level utilization numbers.
